Описание кейса

Проблема

Ручной контроль геометрии деталей медленный, субъективный и поэтому выборочный.

Задача

ПО, которое по изображению детали автоматически выполняет двумерные измерения и морфологический анализ.

  • Инженер по качеству

    Получает размеры детали без ручных замеров.

  • Задача

    Проверить геометрию детали.

  • Решение

    ПО выделяет контуры по изображению и измеряет размеры.

  • Технологии

    Машинное зрение, морфологический анализ, двумерные измерения.

  • Коротко

    Многофункциональная размерная аналитика.
